## 🎯 نمای کلی

این پروژه یک طبقه‌بند XGBoost را برای پیش‌بینی لغو یا عدم لغو رزرو هتل پیاده‌سازی می‌کند. مدل از ویژگی‌های مختلفی مانند زمان رزرو، تاریخ ورود، مدت اقامت، اطلاعات مهمان و ویژگی‌های رزرو برای پیش‌بینی استفاده می‌کند.

## ✨ ویژگی‌ها

- **تحلیل داده**: تحلیل اکتشافی داده‌های رزرو هتل
- **طبقه‌بندی XGBoost**: پیاده‌سازی gradient boosting برای طبقه‌بندی باینری
- **تنظیم ابرپارامترها**: جستجوی تصادفی برای پارامترهای بهینه مدل
- **ارزیابی مدل**: اعتبارسنجی متقابل و معیارهای دقت
- **اهمیت ویژگی‌ها**: نمایش بصری ویژگی‌های مهم
- **درخت‌های تصمیم**: نمایش بصری درخت‌های تصمیم XGBoost

```bash

```

این دستور بسته‌های زیر را نصب می‌کند:
- `pandas` - دستکاری و تحلیل داده
- `xgboost` - چارچوب gradient boosting
- `numpy` - محاسبات عددی
- `scikit-learn` - ابزارهای یادگیری ماشین
- `matplotlib` - نمایش بصری داده
- `jupyter` - محیط Jupyter Notebook

## 🚀 نحوه استفاده

### اجرای نوت‌بوک

1. **شروع Jupyter Notebook:**
   ```bash
   jupyter notebook
   ```

2. **باز کردن نوت‌بوک:**
   - به `XGBoostHotelBookings.ipynb` در رابط Jupyter بروید
   - روی نوت‌بوک کلیک کنید تا باز شود

3. **اجرای سلول‌ها:**
   - سلول‌ها را به ترتیب با `Shift + Enter` اجرا کنید
   - یا همه سلول‌ها را با `Cell > Run All` از منو اجرا کنید

### جریان کاری مورد انتظار

نوت‌بوک این جریان کاری را دنبال می‌کند:

1. **نصب XGBoost** (در صورت عدم نصب قبلی)
2. **وارد کردن کتابخانه‌ها** - بارگذاری بسته‌های Python لازم
3. **بارگذاری داده** - خواندن فایل `hotel_bookings_clean.csv`
4. **اکتشاف داده** - تحلیل ساختار و آمار دیتاست
5. **نمایش بصری داده** - نمایش توزیع متغیر هدف
6. **همبستگی ویژگی‌ها** - تحلیل همبستگی‌ها با متغیر هدف
7. **آموزش مدل** - آموزش طبقه‌بند XGBoost با پارامترهای پیش‌فرض
8. **ارزیابی پایه** - ارزیابی عملکرد اولیه مدل
9. **اهمیت ویژگی‌ها** - نمایش بصری ویژگی‌های مهم
10. **اعتبارسنجی متقابل** - انجام اعتبارسنجی متقابل برای ارزیابی مدل
11. **تنظیم ابرپارامترها** - بهینه‌سازی پارامترهای مدل با استفاده از RandomizedSearchCV
12. **ارزیابی نهایی** - ارزیابی مدل بهینه شده

## 📊 دیتاست

پروژه از **دیتاست تقاضای رزرو هتل** استفاده می‌کند که شامل:
- **119,210 ردیف** داده رزرو
- **53 ستون** شامل ویژگی‌ها و متغیر هدف
- **متغیر هدف**: `is_canceled` (باینری: 1 = لغو شده، 0 = لغو نشده)

### ویژگی‌های دیتاست شامل:
- زمان رزرو (lead time)
- اطلاعات تاریخ ورود (شماره هفته، روز، ماه)
- مدت اقامت (شب‌های آخر هفته، شب‌های هفته)
- اطلاعات مهمان (بزرگسالان، کودکان، نوزادان)
- ویژگی‌های رزرو (مهمان تکراری، لغوهای قبلی)
- نوع هتل (شهری/تفریحی)
- نوع وعده غذایی
- بخش بازار
- و موارد بیشتر...

**منبع دیتاست**: [Kaggle - Hotel Booking Demand](https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand)

## 📈 عملکرد مدل

مدل به عملکرد زیر دست می‌یابد:

- **دقت پایه**: حدود 81.5%
- **دقت اعتبارسنجی متقابل**: حدود 81.5%
- **دقت مدل بهینه شده**: حدود 83.5% (پس از تنظیم ابرپارامترها)

### بهترین پارامترهای یافت شده:
- `max_depth`: 10
- `n_estimators`: 40
- `learning_rate`: حدود 0.17
- `subsample`: 0.5
- `alpha`: 0.001
